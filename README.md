# Daywell

A small, local-first web app for tracking daily actions and how satisfying they felt.

## Run

Open `index.html` in a modern browser. No installation or build step is required.

## Use

- Log an action, choose an activity and section, enter its numbers, and rate satisfaction from 1 to 5.
- The starter activities are Exercise → Stepper (Strength and Minutes), Writing, Journaling, and Other projects.
- Use **Activities** to add activities, sections, and numeric fields.
- Use the date picker to log a past day. **History** shows previous entries and can export a JSON backup.

Data is stored in this browser's local storage. It stays on this device and will be lost if that browser's site data is cleared; use the export button to keep a backup.
