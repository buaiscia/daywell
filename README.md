# Daywell

A small, local-first web app for tracking daily actions and how satisfying they felt.

## Run

Open `index.html` in a modern browser. No installation or build step is required.

## Use

- Log an action, choose an activity and section, enter its numbers, and rate satisfaction from 1 to 5.
- The starter activities are Exercise → Stepper (Strength and Minutes), Writing, Journaling, and Other projects.
- Use **Activities** to add activities, sections, and numeric fields.
- Choose a date in the logging form to add an action for today or a past day. You can also change the date when editing an action. **History** shows previous entries and can export a JSON backup.
- Use **Todos** to save simple dated todos with a title and an optional short description. Edit or delete a todo with its row buttons. Check one to move it to the Archive tab; uncheck it there to return it to Active.
- Elliptical logs in Exercise → Stepper estimate calories from strength (1–8), minutes, and body weight. The estimate starts at 70 kg and can be changed while logging; it is a rough guide because machine settings and pace differ.

Data is stored in this browser's local storage. It stays on this device and will be lost if that browser's site data is cleared; use the export button to keep a backup.
